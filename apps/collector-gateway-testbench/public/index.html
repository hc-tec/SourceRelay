02 · ONE-SHOT READ-ONLY WORK

测试工作流

大多数能力最多一次导航；小红书能力只使用唯一已有公开标签页。不会自动重试；任何可信输入或滚动都有固定预算。

先配置 Local API token 并刷新 binding。
A

B站视频详情

仅接收 BVID；服务端推导规范视频地址。

X

小红书公开笔记站内搜索

仅接收查询词；可选深挖详情与评论区。要求日常浏览器已经存在唯一公开 Explore tab；零 URL 跳转、零刷新、零新 tab。

X2

小红书博主公开笔记

可选择已有公开主页 tab，或提交一次短时公开主页链接；链接模式只在已有小红书 tab 内导航一次，Network 优先并在预算内收集公开笔记。

X3

小红书公开笔记详情

要求浏览器中恰好存在一个公开搜索结果 tab。只接收当前可见结果排名 1–20；零 URL、零刷新、零新 tab，一次可信点击打开同页详情浮层，Network 优先、DOM 回退。

X4

小红书公开笔记评论

仅使用当前已经打开的详情浮层；零导航、零刷新，执行 1–3 次有账本的可信滚动。

X5

小红书公开评论回复

仅展开当前详情浮层中最多三个可见回复线程；Network archive 优先，每个线程最多一次可信点击。

B

B站站内搜索

仅接收关键词；固定综合、相关性与第 1 页。

B2

B站站内搜索（固定两页）

仅接收关键词；服务端固定第 1、2 页，零页面点击、最多两次 URL 导航。

C

UP 主公开资料

仅接收 UP 主 MID；服务端推导规范空间主页。

D

UP 主视频首屏

仅接收 UP 主 MID；可由扩展新建受管工作页，或只被动观察你刚从扩展 popup 明确选择的投稿首页；不翻页、不滚动。

E

视频评论区

只提交 BVID；扩展使用自有工作标签页完成一次有界导航和评论区 DOM 投影，不会接收 tab ID、滚动、排序、展开回复或刷新指令。

F

首批宿主浏览器被动能力

仅允许已登记的固定目标：动态、合集概览/详情或视频弹幕 DOM；一次导航，零页面点击。
